# HRIDAY Evaluation Metrics

All metrics must have an explicit status: Target, Measured, or Paper Result.

## Extraction

- object precision / recall
- critical tag exact-match rate
- text association accuracy

## Topology

- edge precision
- edge recall
- junction-vs-crossing accuracy
- directionality accuracy

## Graph

- path accuracy
- entity resolution accuracy
- provenance completeness

## Answer

- query correctness
- evidence attribution correctness
- unsupported-claim rate

## Human verification

- review rate
- correction rate
- unresolved ambiguity rate

## Product

- processing latency
- manual tracing time on defined benchmark tasks

Never present targets as achieved results. Never present a paper's metric as an HRIDAY measurement.

# MVP Scope

## In scope

- local P&ID upload
- supported visual extraction
- bounded topology reconstruction
- provenance-aware graph
- constrained natural-language graph query
- evidence mapping
- confidence gate
- human verification
- polished golden demo

## Explicitly deferred

- full DEXPI conformance
- exhaustive ISA-5.1 ontology
- custom foundation-model training
- production-scale distributed processing
- plant control/integration
- autonomous HAZOP or LOTO decisions
- broad enterprise document RAG
- cloud dependency

The prototype wins by proving one difficult vertical slice, not by pretending to solve every industrial workflow.
